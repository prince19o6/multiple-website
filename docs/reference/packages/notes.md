# Live Site Reference Audit: Packages & Holidays Module (`/en/holidays`)

## 1. Landing Page (`/en/holidays`)
- **URL**: `https://www.gujjutours.com/en/holidays` (and `/en/domestic-holidays`)
- **Hero Title**: "Book Customized Holiday Packages for Every Budget"
- **Search Widget**:
  - Fields: Destination city or country autocomplete, Month of Travel, Duration range (e.g. 3-5 Days, 6-8 Days, 9+ Days), Travelers count, Budget tier.
  - Search CTA: "Search Packages".
- **Landing Sections & Collections (Pre-Search)**:
  - "Explore Scenic Escapes Across India & Beyond" (Mountain, Beach, Nature & Wildlife).
  - "Spiritual Escapes at Best Prices" (Char Dham, Kashi, Somnath, Dwarka, Tirupati).
  - "Discover Visa-Free Escapes" (Thailand, Malaysia, Maldives, Sri Lanka, Kazakhstan, Mauritius).
  - "Dream Honeymoon Getaways" (Bali, Switzerland, Paris & Amsterdam, Kashmir, Kerala).
  - "Themed Curated Package Groups":
    - **Dubai Packages** (Dubai Budget Escape 3 Nights, Dubai Luxury Escape 5 Nights, Ferrari World Tour).
    - **Jain Packages** (Guaranteed Jain pure vegetarian food arrangements, dedicated kitchens).
    - **International Packages** (Southeast Asia, Europe, Middle East).
    - **Domestic Packages** (Kashmir, Himachal, Goa, Golden Triangle, South India).

## 2. Package Card Structure
- Package Cover Image with duration pill (e.g. `5 Days / 4 Nights`).
- Package Title (e.g. `Dubai Luxury Escape 5 Nights`).
- Cities Covered (e.g. `Dubai (3N) + Abu Dhabi (2N)`).
- Key Inclusions: `4★ Hotel`, `Sightseeing`, `Airport Transfers`, `Daily Breakfast`.
- Rating (`4.8 (340 reviews)`).
- Starting Price: `₹42,500` per person on twin sharing basis.
- CTA: "View Itinerary" / "Send Enquiry".

## 3. Detail Page (`/en/holidays/<country-id>/<city-id>/<slug>-<id>`)
- Daily Itinerary Day-by-Day breakdown with meals and transfers.
- Hotel Stays included (hotel name, room category, nights).
- Activity vouchers included.
- Inclusions & Exclusions.
- Departure dates / Monthly price calendar.
- Request Customization lead modal & instant booking option.
