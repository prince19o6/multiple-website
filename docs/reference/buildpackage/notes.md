# Live Site Reference Audit: Build Package Module (`/en/buildpackage`)

## 1. Landing & Custom Builder Page (`/en/buildpackage`)
- **URL**: `https://www.gujjutours.com/en/buildpackage`
- **Hero Title**: "Customized Holiday Experiences Built for You"
- **Step-by-Step Package Builder Engine**:
  - **Step 1: Destination & Dates**:
    - Departure City / Origin.
    - Destination Country & City.
    - Start Date & End Date / Trip Duration (e.g. 5 Days / 4 Nights).
    - Travelers (Adults, Children, Infants).
  - **Step 2: Choose Accommodations (Stays)**:
    - Select from available curated hotels for that destination.
    - Star preference (3-star, 4-star, 5-star luxury).
    - Room type & meal plan (Breakfast Only, Half Board).
  - **Step 3: Add Activities & Experiences**:
    - Multi-select day-wise activities from destination catalog.
    - Example: Day 1 Arrival & Marina Cruise, Day 2 City Tour + Burj Khalifa, Day 3 Desert Safari, Day 4 Free Day.
  - **Step 4: Add Ground Transfers**:
    - Airport Pick-up & Drop-off vehicle selection (Sedan, SUV, Private Van).
    - Intercity or activity transfers toggle.
  - **Step 5: Optional Flight & Visa Add-ons**:
    - Checkbox to include Return Airfare from chosen departure city.
    - Checkbox to include Tourist Visa processing assistance.
  - **Step 6: Real-time Live Price Summary & Checkout**:
    - Dynamic subtotal calculation updating on every selection.
    - Itemized breakdown: Stays + Activities + Transfers + Add-ons + Taxes.
    - Action CTA: "Request Instant Quotation" or "Confirm Custom Package Booking" with approval workflow and itinerary PDF generation.
