# Live Site Reference Audit: Flights Module (`/en/flights`)

## 1. Landing Page (`/en/flights`)
- **URL**: `https://www.gujjutours.com/en/flights`
- **Hero Title**: "Book Cheap Flights Online"
- **Search Widget**:
  - Trip Type: One-Way, Round-Trip, Multi-City.
  - From & To Airport inputs with IATA codes and swap button.
  - Departure Date & Return Date.
  - Passenger Count (Adults, Children 2-11, Infants < 2).
  - Cabin Class: Economy, Premium Economy, Business, First Class.
  - Checkbox: "Direct flights only".
- **Landing Sections & Collections (Pre-Search)**:
  - "Popular Flight Routes" with tabs:
    - **Domestic Flight** (Mumbai to Delhi, Delhi to Bengaluru, Mumbai to Goa, Delhi to Mumbai).
    - **International Flight** (Mumbai to Dubai, Delhi to Singapore, Mumbai to Bangkok, Delhi to London).
  - Route Cards: Origin city, Destination city, Departure airport code, Duration, Daily flight frequency, starting airfare (`From ₹3,499`).
  - "Why Book Flights With Us?" (Zero Convenience Fee on select cards, 24/7 Rescheduling Support, Instant E-Ticket, Web Check-in Assistance).
  - "Flights from Mumbai", "Flights from Delhi", "Flights from Dubai".

## 2. Route Landing Pages (`/en/flights/<from>-to-<to>-flights-<fromCode>-<toCode>`)
- Direct route information, average flight time, top carriers flying this route (e.g. Indigo, Air India, Emirates).
- Fare calendar with price trends.
- FAQ regarding baggage allowance and airport terminals.
